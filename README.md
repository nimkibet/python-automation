4. **🛡️ Non-Maskable Human Priority (IRQ 0):**

## 🚀 Quick Start Guide (New PC Setup)

This repository contains the pre-compiled, self-contained single-file binary runtime (`Nextgen_Workforce.exe`). **No Python installation or manual dependencies are required.**

### Step 1: Automated System Setup
1. Clone or download this repository to your computer:
   ```cmd
   git clone https://github.com/nimkibet/python-automation.git
   cd python-automation
   ```
2. Double-click **`setup_new_pc.bat`**.
   * Automatically configures the stealth hardware driver library (`interception.dll`).
   * Creates a convenient desktop shortcut: **`Nextgen Autonomous Workforce`**.

### Step 2: Launch Automation
You can launch the master interactive suite or any dedicated standalone engine:

* **Master Enterprise Suite:** Double-click **`start_workday.bat`** (or the Desktop shortcut).
* **Dedicated Coding Engine:** Double-click **`start_coding.bat`**.
* **Dedicated Excel Engine:** Double-click **`start_excel.bat`**.
* **Dedicated Browser Engine:** Double-click **`start_firefox.bat`**, **`start_brave.bat`**, or **`start_edge.bat`**.

### Step 3: Product Key Activation
On initial startup:
1. Enter your 16-character Product Key when prompted (e.g., `NX-XXXX-XXXX-XXXX`).
2. The key will cryptographically bind to your PC hardware via the cloud gateway.
3. Your workstation is now fully licensed and operational.
